# 0050 提領計算機

退休金每月領多少，才能永續提領？這是一個單頁 HTML 小工具：填本金、想領的金額、借款與利率，拖動「股市漲跌」滑桿，就能看到這個情境下每月拿多少、安不安全、要不要暫停。門檻不是抄美國的 4% 法則，而是拿 0050 與加權指數的歷史資料重跑出來的（見 `backtest/`）。

> 歷史回測，不是保證。

## 兩種提領方式

| | 固定提領 | 動態提領 |
|---|---|---|
| 怎麼領 | 每月領固定金額 | 每年 1 月看部位 × 提領率，除以 12 按月領 |
| 保護機制 | 保險絲：部位跌破起始本金 60% 暫停，回到 70% 恢復 | 金額跟著部位縮水，不用保險絲 |
| 門檻（領的加利息占起始本金） | 6.4% 內最穩，7.6% 是上限 | 6.8% 內免調整，8.8% 內要配 GK 三條規則 |

## 公式

金額單位都是「萬」，比例都以起始本金為分母。

| 項目 | 公式 |
|---|---|
| 一年利息 | 借款 × 年利率 |
| 每月利息 | 借款 × 年利率 ÷ 12 |
| 固定：總比例 | (每月 × 12 + 一年利息) ÷ 本金 |
| 固定：穩 / 上限每月金額 | max(0, (本金 × 6.4% 或 7.6% − 一年利息) ÷ 12) |
| 動態：總比例 | 提領率 + 一年利息 ÷ 本金 |
| 動態：每月金額 | 部位 × 提領率 ÷ 12 |
| 股市漲跌後的部位 | 本金 × (1 + 漲跌幅) |
| 保險絲 | 停領線 = 本金 × 60%，恢復線 = 本金 × 70% |
| 反推需要的本金 | (每月 × 12 + 一年利息) ÷ 7.6%（領到上限）到 ÷ 6.4%（穩穩地領） |
| 壞年桶 | 每月金額 × 20 個月 |

### 門檻怎麼來

`backtest/backtest.py` 用本金 1000 萬、借款 1000 萬、年利率 2.76% 跑歷史，每個月份都當一次起點：

- 固定每月 3 萬：(36 + 27.6) ÷ 1000 = 6.36%，保險絲一次都沒響，取 **6.4%** 當「最穩」
- 固定每月 4 萬：(48 + 27.6) ÷ 1000 = 7.56%，保險絲也沒響；5 萬開始會停 18 個月，取 **7.6%** 當「上限」
- 動態部位 4%：4% + 2.76% = 6.76%，兩份歷史都零破產，取 **6.8%**
- 動態部位 6%：6% + 2.76% = 8.76%，嚴苛版開始有路徑歸零，取 **8.8%** 當要配 GK 規則的上限

### 顯示規則

為了讓畫面上的數字和「安不安全」的判斷永遠一致：

- 判斷直接拿原始比例跟門檻比（容許 1e-9 的浮點誤差），不先四捨五入
- 拿來跟門檻比的百分比（例如「加利息共 6.4%」）**無條件進位**到小數一位：顯示 7.6% 就保證沒超過 7.6%
- 「穩 / 上限每月最多領多少」**無條件捨去**到小數一位：照著畫面上的數字填，一定落在對應範圍內
- 其他金額四捨五入，並先去掉浮點雜訊（例如 1192.5 不會因為浮點誤差變成 1192）

## 檔案結構

```
index.html          頁面（HTML、CSS、畫面邏輯）
calc.js             計算邏輯，全部是純函式，瀏覽器與 Node 共用
tests/
  calc.test.js      calc.js 的單元測試（不需要任何套件）
  reference.py      用 Python Decimal 獨立重算的參考實作
  e2e.js            用瀏覽器打開頁面，比對數字、互動、排版
backtest/           歷史回測程式與資料，門檻的出處
docs/screenshots/   手機版與桌機版截圖
```

## 在本機打開

不需要安裝任何東西，直接用瀏覽器打開 `index.html` 即可（雙擊檔案，或拖進瀏覽器視窗）。`index.html` 和 `calc.js` 要放在同一個資料夾。

如果想用本機伺服器開：

```bash
python3 -m http.server 8000
```

再打開 http://localhost:8000/ 。網址加 `#dyn` 會直接進動態提領。

## 跑測試

單元測試只需要 Node.js 18 以上：

```bash
node tests/calc.test.js
```

或

```bash
npm test
```

有安裝 `python3` 的話，單元測試會順便跟 `tests/reference.py` 的獨立計算結果比對；沒有就自動略過那一項。

瀏覽器測試（檢查頁面數字、錯誤提示、鍵盤操作、375px 與 1280px 排版、console error）需要 Playwright：

```bash
npm i -D playwright && npx playwright install chromium
```

```bash
node tests/e2e.js
```

加 `--shots docs/screenshots` 會順便更新截圖。

## 重跑回測

```bash
python3 backtest/backtest.py
```

會印出表格並更新 `backtest/results.json`。加 `--refresh` 會先從 Yahoo Finance 重抓月資料（需要網路）。
